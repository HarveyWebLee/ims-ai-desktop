# 周界防区设定

> 英文名：Perimeter Zone Setting  
> 模块 ID：`perimeter_setting`  
> 所属业务域：配置管理（`/config_management/config`）  
> 来源：平台功能模块知识库（本仓 `prj-docs`）

## 模块说明

管理周界防区列表与维护，支持手动撤布防及撤布防记录查询。

## 适用场景

设备接入、变量采集、事件联动、周界安防、报警与历史数据分析等配置与运维场景。

## 功能页面

| 页面       | 路径                  | 路由                                            | 说明                 |
| ---------- | --------------------- | ----------------------------------------------- | -------------------- |
| 防区列表   | `group`               | `/config_management/config/group`               | 维护防区分组/列表。  |
| 防区维护   | `maintenance`         | `/config_management/config/maintenance`         | 对防区进行维护配置。 |
| 手动撤布防 | `manual_cycle_disarm` | `/config_management/config/manual_cycle_disarm` | 手动执行撤防或布防。 |
| 撤布防记录 | `evacuation_record`   | `/config_management/config/evacuation_record`   | 查询撤布防操作记录。 |

## 操作指引（通用）

1. 登录综合信息管理平台，从门户进入「配置管理平台」。
2. 打开左侧「配置管理」→「周界防区设定」。
3. 在列表页按条件查询；通过新增/编辑/删除维护数据（具体按钮以页面为准）。
4. 若页面含树形筛选（区域/组织/类别），先选节点再操作右侧列表。
5. 无菜单权限时，请管理员在「角色授权 / 菜单管理」中分配。

## 关联依赖

依赖防区相关设备与权限；撤布防记录用于安防审计。

## 常见问题

- **看不到本模块菜单**：检查账号角色是否授权；超级管理员可在「菜单管理 / 角色授权 / 场景管理」配置。
- **列表无数据**：确认筛选条件、所属区域/组织节点，以及后端服务与数据权限范围。
- **无法保存**：检查必填项、字典引用是否存在，以及是否具备写权限。
