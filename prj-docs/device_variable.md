# 设备变量

> 英文名：Device Variable  
> 模块 ID：`device_variable`  
> 所属业务域：配置管理（`/config_management/config`）  
> 来源：平台功能模块知识库（本仓 `prj-docs`）

## 模块说明

配置设备一次/二次变量、查看实时数据，并设置变量报警规则。

## 适用场景

设备接入、变量采集、事件联动、周界安防、报警与历史数据分析等配置与运维场景。

## 功能页面

| 页面         | 路径                 | 路由                                           | 说明                                 |
| ------------ | -------------------- | ---------------------------------------------- | ------------------------------------ |
| 设备变量     | `var`                | `/config_management/config/var`                | 配置设备采集变量（点位）。           |
| 二次变量     | `second_var`         | `/config_management/config/second_var`         | 基于一次变量配置计算型二次变量。     |
| 实时数据     | `real_time_var_data` | `/config_management/config/real_time_var_data` | 查看变量实时值，用于联调与值班监视。 |
| 变量报警配置 | `var_alarm_config`   | `/config_management/config/var_alarm_config`   | 为变量配置报警阈值与报警属性。       |

## 操作指引（通用）

1. 登录综合信息管理平台，从门户进入「配置管理平台」。
2. 打开左侧「配置管理」→「设备变量」。
3. 在列表页按条件查询；通过新增/编辑/删除维护数据（具体按钮以页面为准）。
4. 若页面含树形筛选（区域/组织/类别），先选节点再操作右侧列表。
5. 无菜单权限时，请管理员在「角色授权 / 菜单管理」中分配。

## 关联依赖

依赖监控设备；变量报警、事件联动、历史查询依赖本模块点位。

## 常见问题

- **看不到本模块菜单**：检查账号角色是否授权；超级管理员可在「菜单管理 / 角色授权 / 场景管理」配置。
- **列表无数据**：确认筛选条件、所属区域/组织节点，以及后端服务与数据权限范围。
- **无法保存**：检查必填项、字典引用是否存在，以及是否具备写权限。
