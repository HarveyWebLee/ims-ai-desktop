# 监控设备

> 英文名：Monitor Equipment  
> 模块 ID：`monitor_equipment`  
> 所属业务域：配置管理（`/config_management/config`）  
> 来源：平台功能模块知识库（本仓 `prj-docs`）

## 模块说明

维护监控设备台账、动态属性与设备连接关系，支撑上层变量采集与组态展示。

## 适用场景

设备接入、变量采集、事件联动、周界安防、报警与历史数据分析等配置与运维场景。

## 功能页面

| 页面         | 路径                        | 路由                                                  | 说明                                            |
| ------------ | --------------------------- | ----------------------------------------------------- | ----------------------------------------------- |
| 设备管理     | `equipment_manage`          | `/config_management/config/equipment_manage`          | 设备增删改查、关联区域/类型，是监控设备主台账。 |
| 设备动态属性 | `device_dynamic_property`   | `/config_management/config/device_dynamic_property`   | 维护设备动态扩展属性。                          |
| 设备连接图   | `device_connection_diagram` | `/config_management/config/device_connection_diagram` | 可视化查看或维护设备连接拓扑。                  |

## 操作指引（通用）

1. 登录综合信息管理平台，从门户进入「配置管理平台」。
2. 打开左侧「配置管理」→「监控设备」。
3. 在列表页按条件查询；通过新增/编辑/删除维护数据（具体按钮以页面为准）。
4. 若页面含树形筛选（区域/组织/类别），先选节点再操作右侧列表。
5. 无菜单权限时，请管理员在「角色授权 / 菜单管理」中分配。

## 关联依赖

依赖数采/区域/设备类型；被设备变量、报警、历史数据引用。

## 常见问题

- **看不到本模块菜单**：检查账号角色是否授权；超级管理员可在「菜单管理 / 角色授权 / 场景管理」配置。
- **列表无数据**：确认筛选条件、所属区域/组织节点，以及后端服务与数据权限范围。
- **无法保存**：检查必填项、字典引用是否存在，以及是否具备写权限。
